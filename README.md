# SmartRisk: Intelligent Insider Threat Detection Using Machine Learning

## 📌 Project Overview
SmartRisk is a machine learning-powered cybersecurity application designed to detect potential insider threats by analyzing employee behavior patterns. It leverages a **Random Forest Classifier** to classify activity as **Normal** or **Suspicious** and generates a risk score.

## 🎯 Problem Statement
Insider threats pose serious risks to organizations. Traditional rule-based monitoring systems are rigid and often fail to adapt to evolving attack patterns. SmartRisk provides a data-driven solution for proactive threat detection.

## ✅ Key Features
- Single-user prediction  
- Bulk CSV analysis  
- Risk score generation  
- Feature importance visualization  
- Downloadable prediction reports  
- Interactive Streamlit dashboard  

## 🛠 Technology Stack
- **Programming Language:** Python  
- **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib  
- **Framework:** Streamlit  
- **Version Control:** GitHub  

## 🤖 Machine Learning Model
SmartRisk uses a **Random Forest Classifier** trained on employee activity features:
- Login time  
- Failed login attempts  
- USB usage  
- File access  
- Email activity  
- Downloads  
- After-hours access  

## 🔄 Workflow
1. Data collection (CSV format)  
2. Preprocessing and feature extraction  
3. Model training and prediction  
4. Risk score generation  
5. Dashboard visualization and reporting  

## 🚀 Future Enhancements
- Integration with real-time enterprise monitoring systems  
- Deep learning models for improved accuracy  
- Cloud deployment for scalability  

## 📌 Conclusion
SmartRisk provides an intelligent, practical solution for insider threat detection. With its interactive dashboard and reporting features, it enables organizations to proactively assess risks and strengthen cybersecurity defenses.
